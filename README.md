# أعياد ميلاد الصغار 🎂

تطبيق ويب بسيط وأنيق لتذكّر أعياد ميلاد أطفالك.

**للعائلة فقط — البيانات تُحفظ محلياً على جهازك.**

## الميزات

### أساسية
- إضافة أطفال (اسم + تاريخ ميلاد + صورة)
- عدّ تنازلي لأيام عيد الميلاد القادم مع حلقة تقدّم
- عرض «الأقرب موعداً» بشكل بارز

### التحسينات (الإصدار 2)
- **تعديل** بيانات الطفل بالضغط على البطاقة
- **تأكيد قبل الحذف**
- **تصدير / استيراد** البيانات (نسخة احتياطية JSON)
- **تذكيرات متعددة الأيام** (يوم العيد، يوم، 3 أيام، أسبوع، أسبوعين)
- **وضع فاتح / داكن**
- **نافذة احتفال** + كونفيتي في يوم العيد
- رسائل تنبيه لطيفة (Toast)
- تحسينات بصرية وتجربة مستخدم

## طريقة الاستخدام

1. افتح `index.html` في المتصفح
2. أو انشره على GitHub Pages
3. أضفه إلى الشاشة الرئيسية على الهاتف لأفضل تجربة

## الإشعارات

تعمل الإشعارات أثناء فتح الصفحة فقط.  
لأفضل نتيجة: أضف الصفحة إلى الشاشة الرئيسية وافتحها بين الحين والآخر.

## النسخ الاحتياطي

من زر 💾 يمكنك:
- **تصدير** ملف JSON يحتوي على كل الأطفال والإعدادات
- **استيراد** الملف على جهاز آخر

للاستخدام الشخصي والعائلي.
